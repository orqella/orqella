# Roadmap

Orqella is an early-stage local-first dashboard. This roadmap is intentionally
short and may change as the product is exercised on real machines.

## Now

- Keep the daemon, dashboard, module runtime, and desktop client stable on
  Linux, macOS, and Windows.
- Finish the public module review path so first-party modules can be published
  as they are checked.
- Harden local service installation, updates, backups, and diagnostics.
- Keep the browser and desktop clients aligned on app-surface and permission
  behavior.

## Next

- Expand the module SDK and developer tooling.
- Improve the first-run experience and module discovery.
- Finish signed release artifacts and update verification.
- Add more automated cross-platform coverage.
- Improve the managed Link experience for enrolled machines.

## Later

- A signed module registry and publisher trust flow.
- More team and multi-user controls.
- Additional first-party modules and integrations.

Native mobile applications are maintained in a separate private repository.
The hosted Orqella Link service and its infrastructure are not part of this
roadmap repository.
