# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private security advisory flow on this repository:
**Security → Report a vulnerability**. Include the affected version or commit,
reproduction steps, and the impact you believe the issue has.

We will acknowledge a report as soon as we can, keep you updated while we
investigate, and coordinate disclosure after a fix is available.

## Scope

Orqella's local daemon and browser shell are in scope. The hosted Orqella Link
service, its control plane, managed relays, and deployment infrastructure are
operated separately and are not part of this repository.

See [docs/SECURITY.md](docs/SECURITY.md) for the threat model, sandbox
guarantees, and the project's security assumptions.
