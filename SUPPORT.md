# Support

## Community support

Use GitHub Issues for reproducible bugs and feature requests. Include the
Orqella version, platform, and a minimal description of the problem. Redact
tokens, private keys, account identifiers, and personal data before posting.

For questions and general discussion, use GitHub Discussions if enabled.

## Security

Do not report vulnerabilities in a public issue. Use GitHub's private security
advisory flow; see [SECURITY.md](SECURITY.md).

## What is not supported here

- Alternate Orqella Link control planes or custom relay configurations.
- The proprietary hosted Link service, billing, or account operations.
- Native mobile application support. Those applications are maintained in a
  separate private repository.
- Private module repositories or third-party integrations.

Local Orqella is free. Orqella Link is a paid managed service; hosted-service
support is handled separately from this repository.
